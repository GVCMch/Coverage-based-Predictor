# cp_checkpoints/

Stores CP model checkpoints generated by `train.py`. Gitignored.

```
cp_checkpoints/
├── CIFAR10/
│   ├── best_model.pt
│   └── latent_space_clusters.npz
├── MNIST/
├── Fashion-MNIST/
└── TinyImageNet/
```

## best_model.pt

```python
{
    'model_state_dict': ...,
    'optimizer_state_dict': ...,
    'epoch': int,
    'val_loss': float,
    'val_auc': float,
    'cluster_centers': np.ndarray,   # [n_clusters, pca_dim]
    'cluster_cp_scores': np.ndarray, # [n_clusters]
    'n_clusters': int,
    'pca_dim': int,
}
```

## latent_space_clusters.npz

```python
{
    'cluster_centers': np.ndarray,
    'cluster_cp_scores': np.ndarray,
    'n_clusters': int,
    'high_risk_clusters': np.ndarray,
    'low_risk_clusters': np.ndarray,
    'risk_threshold': float,
}
```

Generated by:

```bash
python train.py --dataset CIFAR10 --pca_dim 64 --d_model 128 --nhead 4 --num_layers 3 --n_clusters 30 --epochs 100
```
