# coverage_matrices/

Stores per-model, per-criterion coverage data generated by `extract_multi_metric_coverage.py`. Gitignored.

```
coverage_matrices/
├── CIFAR-10/
│   └── multi_metric_coverage/
│       ├── resnet50_NC_coverage.npy
│       ├── resnet50_KMNC_coverage.npy
│       ├── ...
│       ├── resnet50_labels.npy
│       ├── resnet50_fault_flags.npy   # 1=fault, 0=correct
│       ├── resnet50_meta.npz
│       ├── resnet50_criteria_state.pkl
│       └── pca_models.pkl
├── MNIST/
├── Fashion-MNIST/
└── TinyImageNet/
```

Coverage arrays are shaped `[N, D]` where N = num_seeds × K and D varies by criterion and model depth. LSC/DSC are scalars (D=1).

`pca_models.pkl` contains fitted PCA and StandardScaler per criterion. Must be consistent between training and inference.

## Generate

```bash
cd coverage_matrices
python extract_multi_metric_coverage.py --dataset CIFAR10 --num_seeds 10000 --K 15
```
